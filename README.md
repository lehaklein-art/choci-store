# חלון הראווה של צ'וקי

האתר מציג כל עמוד **בדיוק** כמו האתר המקורי בוורדפרס (choci.kinsta.cloud) — אותו עיצוב, סינונים, מיונים, עגלה, מועדפים, מועדון ונגישות —
אבל שומר את העמודים מוכנים מראש בשרת הזה, ולכן הם נפתחים מיד. כשהעכבר עובר מעל קישור, העמוד הבא כבר נטען ברקע.

- עמודים ציבוריים (בית, קטגוריות, מוצרים, מתכונים): נשמרים ומתרעננים ברקע כל 10 דקות (`REVALIDATE`).
- עגלה, קופה, החשבון שלי, הוספה לסל, טפסים ומשתמשים מחוברים: עוברים ישירות לווקומרס, בלי שמירה.
- תמונות וקבצים נטענים ישירות מהשרת המקורי.

משתני סביבה: `WC_URL` (כתובת הוורדפרס), `REVALIDATE` (שניות), `ALLOW_INDEX=1` (לאפשר לגוגל — רק אחרי המעבר).

תיקיית `prototype/` — אב-הטיפוס הראשון שנבנה ברכיבי React, שמור לשימוש עתידי ואינו פעיל.
